# Activity 2: Algorithm Auction

**Module:** 12 - Fancy Data Structures  
**Time:** 20-25 minutes  
**Group size:** 3-4  
**Materials:** Scenario cards; play money or points

## Goal

Choose an algorithm/structure for a scenario and defend cost vs simplicity.

## Auction cases (15 min)

For each scenario, teams bid which tool they will "buy":

- linear search  
- binary search  
- merge sort mindset / sorted data  
- linked list  
- BST  

Scenarios (examples):

1. Guest list checked once at the door (tiny `n`)  
2. Phone book lookups all day (large `n`, sorted)  
3. Undo buffer where inserts at front matter  
4. Dictionary-like keys with ordered traversal needs  

Winning bid must justify Big-O and practicality.

## Share-out (5-8 min)

Instructor reveals a "house choice" and notes when over-engineering loses.

## Exit check

Name one scenario where the "slow" algorithm is still the right call.

## Instructor notes

- Reward reasoning, not jargon density.
- Tie back to linked lists vs arrays/lists in Python.
