# 🗺️ Module Overview (Module 12 - Fancy Data Structures)

---

## Welcome

Welcome to **Module 12: Fancy Data Structures**.

In this module, you'll connect algorithm analysis to structure choice, implement or trace linked lists and binary search trees, and compare growth rates that matter in practice. A short GitHub practice reinforces the list and tree ideas from the readings.

Complete the module activities in the order below for the best learning experience.

---

## 🎯 Learning Outcomes

By the end of this module, you will be able to:

1. Compare common sorting and searching algorithms by Big-O class.
2. Describe linked-list structure and basic insert/traverse operations.
3. Explain binary search tree ordering rules and lookup behavior.
4. Relate tree balance to performance (balanced vs degenerate cases).
5. Recognize exponential and factorial growth as impractical for large inputs.
6. Demonstrate understanding on the module quiz using vocabulary and worked examples.
