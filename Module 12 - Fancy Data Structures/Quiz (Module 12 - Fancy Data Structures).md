## Multiple Choice Questions (10 questions)

1. What is the time complexity (Big O) of searching for an item in an unordered list (e.g., array or linked list)?
   a) O(1)
   b) O(log n)
   c) O(n)
   d) O(n^2)

2. What is the time complexity of binary search where n is the length of the list?
   a) O(1)
   b) O(n)
   c) O(log n)
   d) O(n log n)

3. What is the underlying data structure of the Python built-in list?
   a) Linked list
   b) ArrayList / Dynamic array
   c) Binary search tree
   d) Hash table

4. What is the Big O time complexity of looking up an item in a Python `set` or `dict`?
   a) O(1)
   b) O(log n)
   c) O(n)
   d) O(n^2)

5. What data structure makes Python `dict` (dictionary) operations fast?
   a) Linked list
   b) Binary search tree
   c) Hash table
   d) Stack

6. What is a linked list?
   a) A collection of nodes where each node points to the next
   b) A collection of nodes arranged in a tree structure
   c) A collection of nodes arranged in a grid
   d) A collection of nodes with random connections

7. What is the main advantage of a linked list over an array?
   a) Faster access to elements
   b) More memory efficient
   c) Easier to insert and delete elements
   d) Better for sorting

8. What is a binary search tree?
   a) A tree where each node has at most two children
   b) A tree where each node has exactly two children
   c) A tree where each node has at least two children
   d) A tree where each node has no children

9. What is the time complexity of searching in a balanced binary search tree?
   a) O(1)
   b) O(log n)
   c) O(n)
   d) O(n²)

10. What is the main disadvantage of a linked list compared to an array?
    a) Slower access to elements by index
    b) Harder to implement
    c) More memory usage
    d) Less flexible
