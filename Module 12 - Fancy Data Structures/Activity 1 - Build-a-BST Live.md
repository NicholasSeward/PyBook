# Activity 1: Build-a-BST Live

**Module:** 12 - Fancy Data Structures  
**Time:** 25-30 minutes  
**Group size:** Whole class + table groups  
**Materials:** Whiteboard tree; sticky values

## Goal

Insert values into a BST as a class, then discuss balance and search cost.

## Insert round (12 min)

Start empty. Class inserts this sequence onto the board BST:

`8, 3, 10, 1, 6, 14, 4`

Table groups predict the next node's place before it is drawn.

## Search race (8 min)

Instructor asks: "How many comparisons to find 4? 14? 2 (missing)?"  
Tables answer before the walk is shown.

## Twist (5 min)

Insert a worst-case sequence like `1,2,3,4,5` on a second board. Compare heights.

## Exit check

"A balanced BST helps because ___."

## Instructor notes

- Keep null children visible.
- Connect to Module 10 Big-O intuition; Module 12 goes deeper.
