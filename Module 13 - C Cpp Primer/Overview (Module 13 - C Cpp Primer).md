# 🗺️ Module Overview (Module 13 - C Cpp Primer)

---

## Welcome

Welcome to **Module 13: C Cpp Primer**.

In this module, you'll compare Python with C/C++ syntax and compilation, see why types and memory matter, and complete a first C++ practice that reinforces control flow in a compiled language. This is a short bridge toward languages you may see in later courses.

Complete the module activities in the order below for the best learning experience.

---

## 🎯 Learning Outcomes

By the end of this module, you will be able to:

1. Contrast Python's dynamic typing with C/C++ type declarations.
2. Describe compile-then-run workflow versus interpreted Python execution.
3. Explain stack/heap and manual memory ideas at an introductory level.
4. Read short C++ snippets that mirror Python conditionals and loops.
5. Identify performance motivations for using C/C++ in hot paths.
6. Submit a working C++ practice program through the required GitHub workflow.
