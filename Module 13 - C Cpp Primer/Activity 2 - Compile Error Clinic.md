# Activity 2: Compile Error Clinic

**Module:** 13 - C C++ Primer  
**Time:** 20-25 minutes  
**Group size:** Pairs  
**Materials:** 3 broken C++ files

## Goal

Read compiler diagnostics, fix small C++ mistakes, and explain them in plain English.

## Patients (15 min)

Typical planted issues:

- missing semicolon  
- undeclared variable / wrong type  
- using Python-style indentation mindset without braces  
- `=` vs `==` in a condition  

Pairs log:

| Error message (short) | Actual cause | Fix |
|-----------------------|--------------|-----|
| | | |

## Teach-back (5-8 min)

Pairs exchange one patient with neighbors and confirm the fix still builds.

## Exit check

How is a C++ compile error different from a Python traceback timing-wise?

## Instructor notes

- Show where the compiler points vs the real root cause.
- Optional: one linker error as a stretch (advanced).
