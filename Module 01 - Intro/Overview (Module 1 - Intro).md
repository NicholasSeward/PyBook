# 🗺️ Module Overview (Module 1 - Intro)

---

## Welcome

Welcome to **Module 1: Intro**.

In this module, you'll take your first steps as a programmer: write and run a simple Python program, use comments, explore how languages and number systems work, set up your development tools, and begin using Git and GitHub for coursework. These foundations support everything you do in the rest of this course.

Complete the module activities in the order below for the best learning experience.

---

## 📋 Suggested Learning Path

1. Participate in the discussion (if assigned)
2. Participate in any in-class activities (when scheduled)
3. Complete the required readings and watch the course videos
4. Open the Lecture Resources and review the lecture slides and watch the lecture video
5. Complete the Module Quiz
6. Complete the Guided Tutorial
7. Complete the GitHub Practice Assignment
