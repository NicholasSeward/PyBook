# Activity 1: Number Systems Relay

**Module:** 01 - Intro  
**Time:** 20-25 minutes  
**Group size:** 3-4 students  
**Materials:** Whiteboard or shared doc; scrap paper

## Goal

Convert values between binary, decimal, and hexadecimal quickly and correctly, then explain one conversion to the class.

## Setup (2 min)

1. Form teams of 3-4.
2. Each team picks a scribe and a speaker.
3. Instructor posts 6 conversion challenges (mix of bin/dec/hex).

## Round 1: Quiet solve (8 min)

As a team, solve all challenges on paper. No phones for converters.

Example challenge set (instructor may swap numbers):

1. `13` decimal → binary  
2. `10110` binary → decimal  
3. `255` decimal → hex  
4. `0x2A` hex → decimal  
5. `64` decimal → binary  
6. `0b1111` binary → hex  

## Round 2: Board race (6 min)

Instructor calls one challenge at a time. First team with a correct answer on the board earns a point. Speaker must show work in one sentence.

## Share-out (5 min)

Two teams explain one conversion each:

- What place values did you use?
- Where do people usually slip up?

## Exit check (2 min)

Each student writes one sentence: "Binary is useful because ___."

## Instructor notes

- Keep numbers small so mental math stays fair.
- If a team is stuck, hint: "powers of 2" or "groups of 4 bits for hex."
- Optional stretch: ASCII code for a letter → hex.
