# 🗺️ Module Overview (Module 5 - Iteration)

---

## Welcome

Welcome to **Module 5: Iteration**.

In this module, you'll learn to repeat work with `while` and `for` loops, build running totals with accumulators, and control loop flow with `break` and `continue`. Iteration is how programs process sequences, search data, and automate multi-step tasks.

Complete the module activities in the order below for the best learning experience.

---

## 🎯 Learning Outcomes

By the end of this module, you will be able to:

1. Write `while` loops with clear termination conditions.
2. Write `for` loops over ranges and sequences.
3. Use accumulators and counters to compute running results.
4. Apply `break` and `continue` intentionally (and avoid misuse).
5. Choose between index-based and direct iteration for a task.
6. Solve a multi-step problem that requires nested or sequential loops.
