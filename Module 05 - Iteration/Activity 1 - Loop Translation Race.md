# Activity 1: Loop Translation Race

**Module:** 05 - Iteration  
**Time:** 20-25 minutes  
**Group size:** Pairs  
**Materials:** Laptops or paper; timer

## Goal

Translate the same task between `while` and `for`, and discuss which version is clearer.

## Round A (8 min)

Instructor posts a `while` loop that sums numbers until a sentinel (or prints 1..N).  
Pairs rewrite it as a `for` loop (or `for` + `range`). First five pairs to finish whisper "done" and wait for check.

## Round B (8 min)

New prompt: a `for` loop that counts vowels in a string.  
Rewrite with `while` and an index. Swap papers with another pair for a 2-minute review.

## Debrief (5-7 min)

Discuss:

- When is `for` obviously better?
- When does `while` still win (unknown length, sentinel, user input loops)?

## Exit check

One sentence: "I choose `while` when ___."

## Instructor notes

- Disqualify solutions that change the required behavior.
- Plant one off-by-one hazard in the prompt if you want richer talk.
