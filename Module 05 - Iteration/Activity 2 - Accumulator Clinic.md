# Activity 2: Accumulator Clinic

**Module:** 05 - Iteration  
**Time:** 25 minutes  
**Group size:** 3-4  
**Materials:** Whiteboards

## Goal

Design accumulator patterns as a team, then steal good ideas from neighbors.

## Clinic cases (12 min)

Each group boards **starting values + update step + final use** for two cases:

1. Running total and count → average  
2. Track max (and optionally min) while scanning a list  
3. (Stretch) Count how many values meet a condition  

No full program required: show the pattern clearly.

## Consult rounds (8 min)

Groups rotate clockwise. At each board:

- Add a green check if the pattern is sound
- Add a red note if the initializer or update is wrong

## Share-out (5 min)

Instructor highlights one clean average pattern and one common max-init bug (for example initializing max to 0 when negatives exist).

## Exit check

Fix this idea out loud: "I set `maximum = 0` then loop." When is that wrong?

## Instructor notes

- Force explicit initializer talk; that is the learning target.
- Tie to Practice problems that need totals/counts.
