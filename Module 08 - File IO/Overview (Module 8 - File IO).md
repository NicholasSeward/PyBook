# 🗺️ Module Overview (Module 8 - File IO)

---

## Welcome

Welcome to **Module 8: File IO**.

In this module, you'll read and write files safely, choose open modes, handle path and I/O errors, and explore simple persistence ideas (including pickle and basic DB concepts). Files are how programs keep data after the program stops running.

Complete the module activities in the order below for the best learning experience.

---

## 🎯 Learning Outcomes

By the end of this module, you will be able to:

1. Open, read, and write text files using appropriate modes.
2. Process files line by line and as a whole, choosing an approach that fits memory and task.
3. Use `pathlib` or equivalent path handling for portable file locations.
4. Catch and respond to common I/O errors with `try`/`except`.
5. Explain when serialization (for example pickle) or a simple DB approach is useful.
6. Deliver a GitHub practice that reads and/or writes files correctly.
