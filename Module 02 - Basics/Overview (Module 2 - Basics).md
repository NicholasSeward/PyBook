# 🗺️ Module Overview (Module 2 - Basics)

---

## Welcome

Welcome to **Module 2: Basics**.

In this module, you'll build fluency with variables, types, operators, casting, f-strings, PEP 8 style, and reading error messages so you can write small interactive programs with confidence. These skills are the everyday tools you will use in every later module.

Complete the module activities in the order below for the best learning experience.
