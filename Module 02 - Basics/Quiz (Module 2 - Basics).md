## Multiple Choice Questions (10 questions)

1. What is the correct way to assign a value to a variable in Python?

   b) `n = 17`

3. What is the output of `int(3.9)`?

   d) Error

4. Which function converts a string to a floating-point number?
   a) `int()`
   b) `float()`

5. What is the result of `bool("")`?
   a) `True`
   b) `False`

8. Which of the following is NOT a valid type conversion?

9. What is the result of `"5" + "3"`?
