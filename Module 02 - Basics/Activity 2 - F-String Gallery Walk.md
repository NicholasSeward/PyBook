# Activity 2: F-String Gallery Walk

**Module:** 02 - Basics  
**Time:** 20-25 minutes  
**Group size:** Pairs  
**Materials:** Laptops; wall space, shared slides, or course chat gallery

## Goal

Build a tiny formatted "receipt" with f-strings, then critique clarity and PEP 8 on peer samples.

## Prompt (2 min)

Your pair must print a 4-line receipt for one imaginary purchase:

- item name
- quantity
- unit price
- total

Use at least one f-string and format money to 2 decimal places.

## Build (10 min)

Pairs write and run the program. Keep it under 15 lines.

## Gallery (8 min)

Post output (and code if asked) to the shared gallery. Each pair reviews two others and leaves:

1. One compliment (clear label, good rounding, etc.)
2. One concrete tweak (spacing, naming, extra label)

## Debrief (5 min)

Instructor highlights 2 strong samples and 1 common mistake (forgetting conversion, integer division, missing `:.2f`).

## Exit check

Rewrite this with an f-string (on paper):

```text
name = "Ada"
age = 36
# Goal: Ada is 36 years old.
```

## Instructor notes

- Ban `str` concatenation for this activity so f-strings get real practice.
- If pairs finish early: add tax line at 8.5%.
