# Activity 2: Text Surgery Relay

**Module:** 07 - String Manipulation  
**Time:** 25-30 minutes  
**Group size:** 4 (relay roles)  
**Materials:** Laptops; starting messy string

## Goal

Apply string methods in sequence as a team assembly line, then present the cleaned result.

## Starting patient

```text
"   PyThOn   IS   fun!!!   "
```

Target vibe: normalized, readable sentence or token list (instructor picks exact target).

## Relay roles (rotate every ~4 min)

1. **Trim** - strip ends  
2. **Case** - lower/upper/title as required  
3. **Split** - break into words  
4. **Join / replace** - rebuild and clean punctuation  

Each role may only use methods for their job. Pass the current value to the next person.

## Validate (5 min)

Final group runs one clean script that reproduces the relay result.

## Share-out (5 min)

Compare final strings across teams. Discuss method order: why strip before split?

## Exit check

Name two methods you used and what each changed.

## Instructor notes

- Provide an alternate patient string for advanced groups (emails, CSV-ish lines).
- Discourage regex unless Module timing already covered it.
