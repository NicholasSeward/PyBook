# 🗺️ Module Overview (Module 7 - String Manipulation)

---

## Welcome

Welcome to **Module 7: String Manipulation**.

In this module, you'll treat strings as sequences, use indexing and methods, understand escape characters and character encodings, and apply basic pattern tools where they appear in the readings. Text processing shows up in almost every real program you write.

Complete the module activities in the order below for the best learning experience.

---

## 🎯 Learning Outcomes

By the end of this module, you will be able to:

1. Index, slice, and traverse strings correctly (including zero-based indexing).
2. Use common string methods (`upper`, `strip`, `split`, `join`, `replace`, and similar).
3. Explain and use common escape sequences in string literals.
4. Convert between characters and codes with `ord`/`chr` at an introductory level.
5. Apply a simple regular-expression or pattern task when presented in the module.
6. Build a short program that cleans or analyzes text input.
