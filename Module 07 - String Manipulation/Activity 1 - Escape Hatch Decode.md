# Activity 1: Escape Hatch Decode

**Module:** 07 - String Manipulation  
**Time:** 20 minutes  
**Group size:** 3-4  
**Materials:** Encoded mystery strings on slides

## Goal

Decode strings that use escape sequences, then author one mystery for another team.

## Decode round (8 min)

Teams predict printed output for 4 instructor strings, for example:

```py
print("line1\nline2")
print("col1\tcol2")
print("C:\\Users\\ada")
print("She said \"hi\"")
```

No running yet. Write predictions on paper.

## Reveal (4 min)

Run them. Score predictions. Discuss `\\` vs raw strings briefly if it comes up.

## Author round (6 min)

Each team invents one mystery string (must use at least one escape). Trade with another team to decode.

## Share-out (2 min)

Best mystery wins bragging rights.

## Instructor notes

- Keep away from regex here unless you want a stretch card.
- Watch for confusion between the characters in source vs what prints.
