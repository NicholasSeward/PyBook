# Integrated Development Environments (IDEs)

An IDE (Integrated Development Environment) is software designed to make programming easier. Instead of just writing code in a plain text editor, an IDE gives you extra tools to help you organize, run, and debug your programs.

## Typical features include:

- **Syntax highlighting** – keywords, numbers, and strings are shown in different colors to make code easier to read.
- **Code completion** – the editor suggests how to finish what you're typing.
- **Debugging tools** – step through code, watch variables, and find errors more easily.
- **Project management** – keep all your files organized in one place.
- **Version control integration** – work with GitHub or other systems directly from the editor.

## Popular Options for Python Development

- **VS Code (Visual Studio Code)**: Free, lightweight, and highly customizable with extensions. Works well for Python and integrates nicely with GitHub.
- **GitHub Codespaces**: A cloud-based development environment built on VS Code. Runs entirely in your browser—no installation required. Great for consistent setups and working from anywhere.
- **PyCharm**: A full-featured IDE designed specifically for Python. Offers powerful debugging and project management features.
- **Thonny**: Beginner-friendly IDE often recommended for new programmers. Simple interface, easy to install, and tailored to learning Python.
- **Jupyter Notebook**: A notebook-style environment especially popular in data science and education. Lets you mix code, text, and graphics interactively.

## How We Will Use IDEs in This Course

You may use any environment you like to write your Python code. The most important thing is that you find a setup you are comfortable with.

During class, I will demonstrate examples in different contexts:

- **No IDE (just a text editor and command line)** – to show the fundamentals.
- **PyCharm** – to illustrate a full-featured Python IDE.
- **GitHub Codespaces** – to demonstrate a modern, cloud-based workflow.
