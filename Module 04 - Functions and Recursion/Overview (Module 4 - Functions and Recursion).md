# 🗺️ Module Overview (Module 4 - Functions and Recursion)

---

## Welcome

Welcome to **Module 4: Functions and Recursion**.

In this module, you'll deepen how you design functions: return values, default arguments, breaking problems into cooperating pieces, and building a mental model of the call stack (including simple recursion). These skills help you write clearer programs that scale beyond a single block of code.

Complete the module activities in the order below for the best learning experience.

---

## 🎯 Learning Outcomes

By the end of this module, you will be able to:

1. Write functions that return values and use those returns in expressions.
2. Use default arguments appropriately in function signatures.
3. Decompose a problem into cooperating functions with clear responsibilities.
4. Explain stack frames for a short call chain (including simple recursion).
5. Read function annotations or signatures as documentation of intent.
6. Implement a multi-function solution that meets a stated interface.
