# 🗺️ Module Overview (Module 6 - Data Structures)

---

## Welcome

Welcome to **Module 6: Data Structures**.

In this module, you'll use lists, dictionaries, and tuples; compare mutable vs immutable behavior; and pick structures that fit the data and operations you need. Choosing the right structure makes programs clearer and easier to extend.

Complete the module activities in the order below for the best learning experience.

---

## 🎯 Learning Outcomes

By the end of this module, you will be able to:

1. Create, index, slice, and update lists using common list methods.
2. Store and retrieve values with dictionaries; iterate keys, values, and items.
3. Use tuples for immutable sequences and multiple return values.
4. Explain how mutability affects aliasing and unexpected shared updates.
5. Choose among list, dict, and tuple for a stated problem.
6. Implement a small program that combines at least two structure types.
