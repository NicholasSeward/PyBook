# Activity 1: Structure Speed Dating

**Module:** 06 - Data Structures  
**Time:** 25-30 minutes  
**Group size:** 3  
**Materials:** Scenario cards; whiteboard

## Goal

Argue which structure fits a job: list, dict, or tuple (and why mutability matters).

## Stations (3 rounds × 6 min)

Each trio visits three scenarios (or stays put and gets cards rotated):

1. Student grades that must stay in entered order and get appended often  
2. Lookup employee phone numbers by ID  
3. A point `(x, y)` used as a dictionary key  
4. (Optional) Inventory counts by product SKU  

For each scenario, fill:

| Choice | Why this structure | Why not the others | Mutability note |
|--------|--------------------|--------------------|-----------------|
| | | | |

## Share-out (7 min)

Quick debate on one contested scenario. Instructor crowns a "best default" and names acceptable alternatives.

## Exit check

"Use a tuple when ___."

## Instructor notes

- Accept multiple answers if reasoning is solid.
- Push vocabulary: ordered, keyed lookup, immutable, aliasing.
