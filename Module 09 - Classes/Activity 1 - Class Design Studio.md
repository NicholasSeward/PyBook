# Activity 1: Class Design Studio

**Module:** 09 - Classes  
**Time:** 25-30 minutes  
**Group size:** 3-4  
**Materials:** Whiteboards

## Goal

Design a small class from a scenario, critique a neighbor's interface, then implement only `__init__` and one method.

## Scenario options (pick one)

- `Book` in a tiny library (title, author, checked_in)
- `Player` in a game (name, health, heal/damage)
- `Course` (code, enrollment list, add_student)

## Design (10 min)

Board this table:

| Piece | Decision |
|-------|----------|
| Class name | |
| Attributes | |
| Public methods | |
| What should NOT be public | |

## Critique (5 min)

Rotate boards. Leave: one strength, one interface nit.

## Build slice (8 min)

Implement `__init__` + one method. Demo one call.

## Share-out (5 min)

Compare method names across groups for the same scenario.

## Instructor notes

- Push encapsulation talk without requiring private-name syntax.
- Reject god-classes that do everything in one method.
