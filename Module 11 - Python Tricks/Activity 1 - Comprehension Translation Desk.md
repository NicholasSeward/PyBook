# Activity 1: Comprehension Translation Desk

**Module:** 11 - Python Tricks  
**Time:** 25 minutes  
**Group size:** Pairs  
**Materials:** Laptops

## Goal

Translate loop-based code into comprehensions (and sometimes back) without losing clarity.

## Desk packet (15 min)

Pairs translate 3 snippets:

1. Build squares of 0..9  
2. Keep only even numbers from a list  
3. Build a dict of word → length for a word list  

Rules:

- First write a comprehension  
- Partner must read it aloud in English  
- If it is hard to say, rewrite for clarity (loop OK)

## Review swap (5 min)

Swap with another pair. Mark each solution Clear / Clever-but-risky.

## Share-out (5 min)

Show one clear win and one "please don't nest that."

## Instructor notes

- Ban triple-nested comprehensions.
- Celebrate readability over golf.
