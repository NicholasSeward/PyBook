# 🗺️ Module Overview (Module 11 - Python Tricks)

---

## Welcome

Welcome to **Module 11: Python Tricks**.

In this module, you'll write more concise Python using sets, comprehensions, conditional expressions, lambdas with `map`/`filter`, iterators/generators, and packing/unpacking patterns. These idioms help you express common ideas clearly once you know the basics.

Complete the module activities in the order below for the best learning experience.

---

## 🎯 Learning Outcomes

By the end of this module, you will be able to:

1. Use sets for membership tests and basic set operations.
2. Rewrite suitable loops as list, dict, or set comprehensions.
3. Use conditional expressions and simple lambdas with `map`/`filter` where clear.
4. Explain iterators vs generators at an introductory level.
5. Apply `zip` and unpacking (`*`, `**`) in practical examples.
6. Deliver a practice solution that uses at least one "trick" idiom correctly and readably.
