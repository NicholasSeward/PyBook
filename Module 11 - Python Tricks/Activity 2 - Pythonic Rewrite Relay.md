# Activity 2: Pythonic Rewrite Relay

**Module:** 11 - Python Tricks  
**Time:** 20-25 minutes  
**Group size:** 4 (relay)  
**Materials:** Verbose starter script

## Goal

Improve a verbose script one idiom at a time (`zip`, unpacking, `any`/`all`, set membership, conditional expression).

## Starter (projected)

A clunky script that:

- loops with indices across two parallel lists  
- uses a flag variable for "found"  
- builds a unique collection the long way  

## Relay (12 min)

Each teammate may apply **one** idiom improvement, then pass the laptop.

## Demo (5 min)

Final group runs before/after. Neighbors guess which idioms appeared.

## Debrief (5 min)

Which change helped most? Which was just showing off?

## Instructor notes

- Provide the verbose starter in LMS to save typing time.
- If a rewrite breaks behavior, that team rolls back one step.
