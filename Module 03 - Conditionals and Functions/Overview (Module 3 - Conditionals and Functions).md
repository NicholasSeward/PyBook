# 🗺️ Module Overview (Module 3 - Conditionals and Functions)

---

## Welcome

Welcome to **Module 3: Conditionals and Functions**.

In this module, you'll begin writing programs that make decisions using conditionals and organize code into reusable functions. These concepts are foundational to programming and will be used throughout the remainder of this course.

Complete the module activities in the order below for the best learning experience.

---

## 🎯 Learning Outcomes

By the end of this module, you will be able to:

1. Write chained conditionals that select among multiple cases.
2. Predict results of boolean expressions, including truthy and falsy values.
3. Define and call functions with parameters.
4. Distinguish local and global scope in short examples.
5. Trace simple recursive or nested function calls at a conceptual level.
6. Combine conditionals and functions in a small complete program.
