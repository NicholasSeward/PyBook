# Activity 2: Complexity Sorting Cards

**Module:** 10 - Random and Memory  
**Time:** 25 minutes  
**Group size:** 3-4  
**Materials:** Cards labeled with tasks / short snippets and claimed Big-O

## Goal

Order algorithms by growth rate and justify the ranking out loud.

## Card sort (12 min)

Teams order cards from fastest-growing-worst to best for large `n`, for example:

- find max in unsorted list  
- binary search in sorted list  
- nested loop over `n x n`  
- constant-time dict lookup by key  
- print hello once  

Write the Big-O label beside each.

## Defend (8 min)

Instructor challenges two placements. Teams must cite "what grows when input grows?"

## Share-out (5 min)

Connect to business impact: "10x data → what happens to runtime?"

## Instructor notes

- Accept informal Big-O; precision can wait for Module 12.
- Correct "dict is always O(1)" absolutism gently (average case).
