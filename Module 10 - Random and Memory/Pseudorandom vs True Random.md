# Pseudorandom vs True Random

## What is Random?

Random means unpredictable - you can't guess what comes next. In programming, we often need random numbers for games, simulations, and security.

## Pseudorandom Numbers

Pseudorandom numbers are generated by computers using mathematical formulas. They look random, but they're actually predictable if you know the formula and starting point (called a "seed").

Think of it like a very long, complex pattern. If you start at the same place, you'll always get the same sequence. This is useful for:
- Games where you want the same "random" results each time
- Testing programs with predictable data
- Simulations that need to be repeatable

Python's `random` module uses pseudorandom numbers. When you set a seed with `random.seed(42)`, you'll get the same sequence every time.

## True Random Numbers

True random numbers come from unpredictable physical processes in the real world. Examples include:
- Radioactive decay (timing of particle emissions)
- Atmospheric noise (static in the air)
- Thermal noise (random movement of electrons)
- Quantum effects (behavior of tiny particles)

True random numbers are completely unpredictable and can't be reproduced. This makes them essential for:
- Cryptography and security
- Scientific research
- Any application where unpredictability is critical

## Why Does This Matter?

For most programming tasks, pseudorandom numbers are fine. They're fast, efficient, and good enough for games and simulations. But for security applications like generating passwords or encryption keys, you need true randomness.

The key difference: pseudorandom is predictable if you know the pattern, while true random is unpredictable no matter what you know.
