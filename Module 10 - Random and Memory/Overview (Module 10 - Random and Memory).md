# 🗺️ Module Overview (Module 10 - Random and Memory)

---

## Welcome

Welcome to **Module 10: Random and Memory**.

In this module, you'll generate pseudorandom values, reason about aliasing and copying, and use basic time/space complexity ideas plus simple algorithms and timing tools. These skills help you simulate chance, avoid shared-data bugs, and compare how fast code runs.

Complete the module activities in the order below for the best learning experience.

---

## 🎯 Learning Outcomes

By the end of this module, you will be able to:

1. Use the `random` module to simulate chance events reproducibly with seeds when needed.
2. Distinguish pseudorandom generation from true randomness at a conceptual level.
3. Predict aliasing effects and choose shallow vs deep copy appropriately.
4. Classify simple algorithms with basic Big-O time and space intuition.
5. Time code snippets with the `time` module for rough comparison.
6. Implement a practice program that uses randomness and/or algorithmic patterns correctly.
